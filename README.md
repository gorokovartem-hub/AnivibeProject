# AnimeVibe

AnimeVibe — это веб-приложение для просмотра каталога манги, поиска по MangaDex, просмотра глав и работы с локальной библиотекой изображений в формате WebP.

Проект состоит из Node.js/Express сервера и клиентской части на HTML/CSS/JavaScript.

## Возможности

- Поиск манги через MangaDex
- Просмотр списка манги с пагинацией
- Получение списка глав и страниц для выбранной манги
- Скачивание и конвертация обложек в WebP
- Работа с локальной папкой изображений
- Автоматическая конвертация изображений из папки Saves/Photos в Saves/Photosd
- Поддержка API для интеграции и расширения

## Требования

- Node.js 18+
- npm

## Установка

```bash
npm install
```

## Запуск

### Сервер

```bash
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3000
```

### Разработка

```bash
npm run dev
```

Этот сценарий запускает сервер и конвертер одновременно.

### Конвертация изображений

```bash
npm run convert
```

Скрипт обрабатывает изображения из `Saves/Photos`, конвертирует их в WebP и сохраняет в `Saves/Photosd`.

## Основные API-эндпоинты

### Получение списка манги

```http
GET /api/manga-list?page=1&limit=20
```

### Поиск манги

```http
GET /api/search?q=berserk
```

### Получение списка глав

```http
GET /api/chapters?id=ID_МАНГИ
```

### Получение страниц главы

```http
GET /api/pages?id=ID_ГЛАВЫ
```

### Получение списка локальных изображений

```http
GET /api/images
```

### Скачивание и конвертация обложки в WebP

```http
GET /api/fetch?id=ID_МАНГИ&title=Название
```

## Переменные и папки

### `Saves/Photos`
Папка для исходных изображений. Сюда можно складывать JPG, PNG, BMP, TIFF и другие поддерживаемые форматы.

### `Saves/Photosd`
Папка для уже сконвертированных WebP-файлов. Именно она используется веб-интерфейсом.

### `log.json`
Файл с логом обработанных изображений для учёта уже существующих файлов.

## Используемые технологии

- Express
- Node Fetch
- Sharp
- CORS
- Chokidar (в проекте используется в зависимостях, но основной функционал реализован через Express и конвертер)

## Примечания

- Приложение зависит от MangaDex API, поэтому доступ к интернету необходим для загрузки каталога, поиска и чтения глав.
- Для стабильной работы рекомендуется использовать актуальную версию Node.js.
- В проекте предусмотрена автоматическая подготовка папок `Saves/Photos` и `Saves/Photosd` при запуске.
